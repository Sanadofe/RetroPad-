**Inspirations**
I really wanted to bring vintage and retro tech into the present. This Macropad (RetroPad) allows me to do this, while still looking clean and minimalistic to todays standards. 

**Challenges**
This was my first time trying to make schematics and pcb's. Same goes for the firmware. I think I got there in the end :)

**BOM**
- EC11 Rotary Encoder
- Seeed XIAO RP2040
- 10x MX-Style switches
- 10x through-hole 1N4148 Diodes
- 10x white blank DSA keycaps
- 5x M3x16mm screws
- 5x M3x5mx4mm heatset inserts
